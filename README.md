# Interactive Old Maid Card Game

A text-based Python program that implements the classic card game Old Maid, allowing a user to play matches dynamically against an automated dealer AI "Robot".

## Features
* **Automated Setup:** Handles clean standard playing deck creation (with one queen safely omitted) and random shuffles.
* **Smart Pair Discarding:** Features custom logic to automatically identify, group, and strip out existing pairs from hands during play.
* **Interactive Turn Structure:** Alternates turns dynamically between user choices and random robot AI logic transitions.
* **Input Validation:** Enforces safe player number selection choices boundaries to prevent out-of-range listing index crashes.
